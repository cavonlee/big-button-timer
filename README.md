# 大按键计时器

一个打开就能用的大字计时器网页，专门配「单键 USB 大按键」（默认 Enter 键）做跑酷/体能课的计时。

## 用法

- 页面打开就是计时器；**按大按键（Enter）= 开始 / 暂停 / 继续**；
- 右下角：复位（↻）、开始/暂停（▶/⏸）；右上角：旋转（竖屏也能横着看大数字）、全屏（图标随状态切换）；
- 左上角：主题 —— **底色**（白/黑）、**字体颜色**（黑/白/红/黄/蓝/绿/紫）、**字体**（黑体/数码管/发光/线条）；
- 所有设置都存 `localStorage`，下次打开还是上次那套。

## 加到桌面 / 离线

- 手机浏览器菜单里「**添加到主屏幕**」即可当 App 用；
- 带 Service Worker：**页面已缓存**，断网打开也能计时。

## 部署

纯静态（`index.html` + `fonts/` + `icons/` + `manifest.webmanifest` + `sw.js`），GitHub Pages 托管。
字体：DSEG（OFL-1.1，keshikan/DSEG）。
